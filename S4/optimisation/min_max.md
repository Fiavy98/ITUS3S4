# OPTIMUM

## Fonction un seul variable f(x)

### Calcul de f'(x)
1. f'(x) < 0 : croissante  
2. f'(x) > 0 : decroissante  

### Trouver le points critique
f'(x) = 0  

⇒ Etudier le signe de f'(x) (TV)  
- si f'(x) = 0  
- -1 < x < 1 : dans TV  
  - calcul f(-1) et f(1) : si tjr possitif , pas de solution  

### Calculer f''(x)
1. f''(x) > 0 : minimum  
   - Courbe convexe : ∪  
2. f''(x) < 0 : maximum  
   - Courbe concave : ∩  

⇒ La fonction n'admat pas un optimum si f'(x) = 0 n'as pas de solution  
ou le fonction sont toujours croissant
